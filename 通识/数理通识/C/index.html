    第六章 基本数据类型¶

    6.1 原码、补码、反码¶

    • 正数：符号位为0，原码补码反码均相同
    • 负数：
      • 原码：符号位为1，其余各位表示绝对值
      • 反码：符号位为1，其余各位为原码取反
      • 补码（将正数与负数的计算统一起来）：反码+1

        -1的二进制码是全1（所有Bit都是1）

    • 最大的无符号整数的二进制也是全1（所有Bit都是1）
      C
      int a=-1;  
unsigned b=10;  
if(a<b){   
    printf("<");   
}else{   
    printf(">");    
}

    输出：带符号整数会在比较之前转换成相同类型的无符号整数

    • C语言中，32位的int
      最大值是2^31 -1
      最小值是-2^31

    C
    char a='A';
char b= 65;
char c=0101;
char d='\101';

    • % 是输入输出函数约定的格式控制字符
    • 其余时候直接用%即可，不需要转义

    6.6 格式控制符¶

    %d 十进制
    （以下三个只能输出正整数）
    %u 十进制无符号
    %o 八进制
    %x 十六进制

    • 除了%c，scanf会跳过数据前面的空白字符

    6.7 标准输入流¶

    • 标准输入流（stdin） — 为输入库函数（scanf 等）提供字符流。
    • stdin = standard input ,从键盘缓冲区获取字符序列

    用户通过键盘键入字符，字符存入键盘缓冲区
    用户按下回车键 (return) 后，产生一个换行字符 \n，存入缓冲区
    缓冲区收到 \n 后，将存储的字符序列（包括 \n）转移到 stdin 中
    scanf、getchar 等函数从 stdin 读取字符和数据

    • %n获取目前为止从stdin中消耗的字符数

    6.8 数据类型转换¶

    • 转换的都是数据值的类型，而不是变量类型
      强制类型转换：（类型名）表达式 单目运算

    • 赋值：右边转换为左边

    • 函数：参数调用时，将实参转换为形参后赋值给形参

    有符号整型和无符号整型混合运算时，有符号型要转换成无符号型，运算的结果是无符号的。

    C
    int a=-10;
unsigned b=5;
(a+b>0)==1;

    6.9 算数表达式¶

    C
    i=1;
i++=1;i=2;
++i=3;i=3;
    算术运算>关系运算>逻辑运算>赋值运算
    C
    x=y+=z=2;
--->x=(y+=(z=2));

    10.2项目¶

    • 一个源代码文件太长，适合分成几个文件，but 两个独立的源代码文件不能编译形成可执行的文件
    • 项目→包含多个源代码文件
      • dev c++编译：把一个项目中所有的代码文件都编译后，链接起来
      • VS（Visual Studio）,编译按钮是对单个源代码文件编译，构建按钮是对整个项目做链接
    • 一个.c是一个编译单元
